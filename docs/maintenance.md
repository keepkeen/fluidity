# 同步与主屏维护说明

## 链接同步

`src/services/linkSync.ts` 管理 `link-groups` 与 `fluidity.linkSync.v1`。
分组以标题标识，链接以“分组标题 + URL”标识，保留同一 URL 出现在不同分组的原有行为。
删除分组会为组及其成员写入删除标记；重命名/移动对应旧位置删除、新位置添加。

- 本地编辑统一经 `Settings.Links.set`，链接和元数据在同一可回滚事务中保存。
- 逐项版本采用修改时间，下一次本地修改严格晚于已观察到的版本。同一版本的删除优先于编辑；同时编辑按稳定内容比较收敛。
- favicon 缓存不生成内容修改版本。
- 没有元数据的旧快照按版本 0 迁移，不能用一次不相关的全量备份时间复活已删除链接。
- 删除标记不按固定天数清理，避免长期离线设备恢复旧数据。所有设备需要升级，旧版客户端自身不会执行新合并规则。
- 备份携带元数据；用户主动导入视为一次新的编辑，并保留未被恢复的删除历史。同步拉取直接应用合并版本，不制造新的本地编辑。
- 同步在异步读取 Chrome 存储后重新读取链接，再同步合并和成对写入，保留读取期间发生的本地删除。

`linkSync.test.ts` 覆盖旧设备快照、并发编辑、删除、重命名、重新添加、favicon 更新、同步幂等性和导入回滚。
`gistSync.lifecycle.test.ts` 覆盖真实拉取控制流中的删除竞态与取消操作。

## 主屏模块边界

| 模块 | 职责 |
| --- | --- |
| `HomeGrid.tsx` | 组合页面与控制器，管理小组件和链接操作 |
| `useHomeDrag.ts` | 条目拖动、跨页停留、预览、提交及取消 |
| `useHomePaging.ts` | 页面滑动、长按仲裁、滚轮、快捷键及焦点归还 |
| `useHomePersistence.ts` | 布局变更订阅、互斥保存、版本检查及排序持久化 |
| `SortableHomeItem.tsx` | 单个应用/小组件的渲染和编辑控件 |
| `HomeGrid.styles.ts` | 主屏视觉样式 |
| `homeInteraction.ts` | 传感器、碰撞检测、几何计算与共享交互类型 |

拆分保留拖动期间稳定 DOM 树、松手后提交、跨标签页版本检查与撤销保护。
`npm run test:e2e:home` 执行 37 项主屏/设置/弹窗检查。
完整的 `test:e2e:mv3` 额外包含原生网站权限授权、后台心跳、统计增长及停止写入；页面级自动化无法可靠确认浏览器原生权限弹窗时，需要独立完成该项验收。

## 开发依赖

Vite 保持 6.x，Vitest 保持 4.x，typescript-eslint 保持 8.x，并更新锁文件中的兼容修复。
typescript-eslint 的 minimatch 间接依赖单独覆盖为 11.0.1 或更新的同主版本，修复
[GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)。
该覆盖已通过 ESLint 与 parser project-service 的实际 glob 匹配验证；上游升级其依赖后可移除覆盖。

主屏阴影使用中性暗色，不引用主题背景色；浅色主题不会再产生大面积亮色光晕。
